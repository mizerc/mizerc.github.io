Hugo: helloworld

Hugo is a static site generator developed in Go. It allow your to write your site content using plain markdown files, then it will build the HTML website following templates defined by you (or by some theme from the Internet).

Installing Hugo#

In macOS, you can install Hugo using Homebrew.

1
2

brew update
brew install hugo

Creating a new site#

You can use the following command to start a new Hugo site project:

1
2

hugo new site my-site
cd my-site

Creating the first post#

You can create a new post manually or using Hugo CLI.

  • Manually: You just need to create a new .md file inside content folder. Later, manually write the front matter which is a special syntax to tell hugo some information/metadata about the post.
  • Using the Hugo CLI: Alternativelly, you can create a new post using the CLI, use the following command: hugo new content content/posts/post-1.md.

Grouping posts#

To create a section or collectino of posts, you can just create a new folder inside content. For example, lets create a new post, but lets define the posts folder in the filepath.

1

hugo new content content/posts/big-post/index.md

Hugo Machinery#

Partials#

Hugo Partial is the Hugo way of allowing you to modularize templates files. It is a piece of a layout (HTML) that lives in its own file. Later, you can import the partial from the layout itself. This allow you to expand the capabilities of the site generator, like for example, adding support to LaTeX syntax.

If you analyse the PaperMod theme, you will see that it imports several partials.

Shortcodes#

A Hugo Shortcode is a template content that is invoked from the markup file.

Some shortcodes are built-in. For example the figure shortcode, which allow you to insert images in the middle of your markdown content.

Hugo Directory Structure#

Check out https://gohugo.io/getting-started/directory-structure/.

PaperMod Theme#

About templates and themes#

Hugo uses template files to be able to transform your markdown content into HTML webpage. You can download a collection of templates, aka a theme, from the internet or try to build your own.

Inside each template file, you have access to the Hugo's template language that allow you to structure the markdown content over the HTML structure.

From now on, in this article, we will be using the PaperMod theme. Which is the one being used by this site.

Installing#

We can just clone the theme repository to themes/<theme-name> folder created by Hugo when you initialized the project.

1

git clone https://github.com/adityatelange/hugo-PaperMod themes/PaperMod --depth=1

Then, you need to update the hugo.yaml file to tell hugo to use the installed theme:

1

theme: ["PaperMod"]

Troubleshooting#

When things go wrong, try the following commands to clean cache.

1
2
3

hugo --cleanDestinationDir
hugo server --disableFastRender
rm -rf ./public && hugo server  --panicOnWarning --ignoreCache --disableFastRender --cleanDestinationDir

You can also fully delete the ./public folder, which is generated when you run hugo build or hugo server.

Serving Locally#

You can run hugo locally with a simple hugo server command. Use --buildDrafts flag to include posts with draft: true in the front matter.

1

hugo server --buildDrafts

Hacking/mods/addons#

Overriding Theme Files#

You can override a theme feature by copying the relevant file from the theme’s layouts folder into your project’s layouts folder.

Remember you cloned the PaperMod repository into ./themes/ folder. But you want to avoid modifying the original theme files. So you copy any file from that folder into the ./layout folder. Hugo will prioritize the file in your project’s layouts folder over the corresponding file in the theme.

For example, if you want to modify index.html, copy themes/foo/layouts/index.html to layouts/index.html.

I copied extend_head.html to ./layouts/_partials/extend_head. That file is imported by PaperMod inside the <head> element. In that file I added support to TeX, Google Analytics, etc.

See Override a Hugo Theme for more information.

Modifying CSS#

You can modify the CSS used by the theme to adjust things like the font-family of the <h1> tag, or the letter spacing used by paragraphs.

One way of doing that is by modifying the extended_head.html partial file to include a custom CSS file which will overwride a specific CSS selector used by the theme.

You can store the custom.css file inside the static folder: ./static/custom.css.

To make things even more fun, you can get the filename from the Hugo config file!

Add a new entry into hugo.yaml

1
2

params:
  custom_css: ["custom.css"]

Then, modify the extended_head.html to import the file. Avoid modifying the original themes files at themes/PaperMod/layouts/partials/header.html, instead copy it to the layout folder to keep the original theme file intact.

Then you can read the value from the Hugo configuration file using the following syntax:

1
2
3

{{ range .Site.Params.custom_css -}}
    <link rel="stylesheet" href="{{ . | absURL }}">
{{- end }}

Custom Code Syntax Highlight#

From https://gohugo.io/quick-reference/syntax-highlighting-styles/:

By default, Hugo applies syntax highlighting using inline CSS styles. To use an external CSS file instead, set noClasses to false in your configuration, then generate the stylesheet with the hugo gen chromastyles command.

1

hugo gen chromastyles --style=monokailight > themes/PaperMod/assets/css/includes/chroma-styles.css

Syntax Highlight with Light/Dark mode#

From: https://gohugo.io/configuration/markup/#highlight

The new Hugo (0.166+) supports light/dark mode for syntax highlight.

Run the following to create the theme file for light mode:

1

hugo gen chromastyles --style=monokai --mode=light > assets/css/highlight.css

And dark mode:

1

hugo gen chromastyles --style=monokai --mode=dark --modeSelector > assets/css/highlight-dark.css

Note that not all themes support light/dark modes.

Adding Google Analytics#

To add analytics to your Hugo website, assuming your current theme doesn’t support it automatically by just updating the settings in hugo.yaml, do the following:

  • Go to analytics.google.com, crete your account, and copy the code provided by Google.
  • Create a new partial file called analytics in hugo_root/layouts/_partials/google/analytics.html
  • Paste the code there, save, close
  • Include the partial in your theme. Copy the original theme file from themes/PaperMod/layouts/partials/head.html to ./layout/_partials/head.html, then modify the later to include the created partial using {{ - partial "google/analytics.html" . -}}.
